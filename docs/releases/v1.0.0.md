# 自动配乐 v1.0.0

由 yuyuyu-a 独立维护的首个版本。源码默认分支、安装包、下载页和应用内更新均属于
`yuyuyu-a/auto-bgm`，不是原项目的安装包。

## 下载与运行

下载下方 **`auto-bgm-setup-1.0.0.exe`**，安装后运行“自动配乐”。
安装包约 657 MiB，适用于 Windows x64，已包含 FFmpeg、faster-whisper small、
YAMNet 及本机运行组件，无需另外下载模型或安装 Python。

`Source code` 是源码，不是安装程序。`.blockmap` 和 `latest.yml` 是应用更新文件，
普通用户不需要手动打开。

安装包目前没有代码签名证书，Windows 可能显示未知发布者。请核对下载来源及文件校验值。

## 已包含的定制功能

- 剧情辅助配乐：结合视频实际对白时间与 TXT、MD、JSON 或 DOCX 剧本、分镜规划音乐。
- 在设置中填写自己的兼容 API 地址、模型和密钥，可获取模型列表和检测连接。
- 支持英文对白；本地从自己的曲库选音乐，保留原声并支持对白时段压低 BGM。
- 曲库支持多层子目录，继承情绪分类；不跟随目录链接，避免重复或越界扫描。
- 每集配乐上限可自定义为任意非负安全整数，0 表示不限；剧情留白不占片段上限。
- 严格纯音乐筛选、人工复核、批量生成、断点继续、时间轴和对白审阅继续保留。

## 独立版说明

- 软件名、安装快捷方式、Windows 应用标识与原项目分开，可以并存。
- 更新仅使用本项目的 Releases，更新缓存不会清理原软件的安装包。
- 首次运行请重新选择视频、曲库、输出目录，并填写自己的剧情 API 配置。
- 不附带任何私人 API 密钥、视频、曲库或个人配置。
- 默认规则模式本地运行；开启剧情辅助时会向所配置服务发送剧本文本、
  带时间对白和类别摘要，服务可能收费，不上传视频和音乐文件。
- 这是自动配背景音乐的软件，不是人物台词自动配音或声线克隆工具。
