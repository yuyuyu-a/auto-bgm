# 自动配乐 v1.0.13

## 本地画面配乐证据校验恢复

- 修复本地视觉模型给出的抽帧时刻或字幕编号不准确时，整段配乐失败的问题。
- 有效且属于当前音乐段的模型证据会保留；缺失或越界引用会根据该批实际提供的抽帧与字幕编号重建。
- 若当前音乐段没有有效抽帧或首条字幕锚点，仍会明确失败，避免输出无依据的配乐。
- 不修改 SRT 或视频，也不需要额外 API 或重新下载本地视觉模型。

## 更新

下载 `auto-bgm-setup-1.0.13.exe` 覆盖安装，原有配置和素材会保留。软件内更新所需的 `.blockmap` 与 `latest.yml` 会和安装包一并发布。
