# 自动配乐 v1.0.10

## 双语 SRT 时间轴

- 支持同一个 `.srt` 文件按顺序包含完整英文字幕轨和完整中文字幕轨；第二轨从两轨共同首条字幕时间重新开始，且两轨使用相同视频时间轴。
- 两轨分别校验时间顺序，再按开始时间稳定合并；同一时刻的双语字幕都会保留。
- 不改写原字幕文件。仍会检查字幕格式、字幕顺序和视频时长；异常时间轴会明确报错。
- 本次为字幕解析兼容更新，不需要重新下载本地视觉模型。

## 更新

下载 `auto-bgm-setup-1.0.10.exe` 覆盖安装，原有配置和素材会保留。软件内更新所需的 `.blockmap` 与 `latest.yml` 会和安装包一并发布。
