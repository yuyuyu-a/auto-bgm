# 自动配乐 v1.0.8

## 大型曲库筛选缓存优化

- 整曲纯音乐分析改为每 25 首保存一次进度，正常结束或手动停止时会保存已完成结果，不再逐曲重写整份增长中的缓存。
- 曲库健康检查会缓存每首代表曲目的完整文件 SHA-256。文件大小或修改时间改变时重算，未变化时复用缓存。
- 健康报告改用曲目索引汇总可用数量，避免大型曲库里对每首曲目反复扫描整个列表。
- 内容重复检测仍逐字节一致，不会因曲名相似而误合并；同名去重、人工确认、禁用和严格纯音乐筛选保持不变。
- 首次筛选仍会完整分析所有尚未缓存的曲目；本更新减少缓存写盘和重复文件读取，不会放宽筛选标准。

## 更新

下载 **`auto-bgm-setup-1.0.8.exe`**，覆盖安装后运行“自动配乐”。现有配置和素材会保留。

`.blockmap` 与 `latest.yml` 是软件内更新器需要的配套文件；一般用户只需下载安装包。本版本不附带私人密钥、视频或曲库。
