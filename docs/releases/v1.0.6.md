# 自动配乐 v1.0.6

- 修复旧版“中性留白、没有音乐”的结果被当作已完成并反复跳过的问题。
- 更新后再次运行“开始批次”或“继续未完成”，旧版规则造成的意外留白会对已勾选的输出自动重配，继续使用相近曲风和抒情替代规则。
- 队列、当前选集和运行日志明确提示待重新生成的旧结果。
- 只更新时间表不会修改未勾选的音频或视频；它们仍保留待修复状态，勾选后再运行会重新生成。
- 曲库没有合格音乐时明确报错，保留原有媒体，不将静音当作新配乐成功。
- 保留原视频、曲库、手工文件保护、API 加密配置、正常成品恢复，以及明确的剧情留白和片尾定格。

请在实际处理视频的电脑更新后，再运行一次受影响的批次。
安装更新本身不会后台改写已有成片，也不会取消纯音乐筛选。
