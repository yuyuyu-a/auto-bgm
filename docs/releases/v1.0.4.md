# 自动配乐 v1.0.4

## 本次更新

- 剧情 API 保留一组配置，不加入多供应商模式。密钥加密保存后，设置页显示固定的 `********` 和“已保存”，不回显真实密钥。
- 重新打开设置或重启软件后无需重复填写。修改地址、模型、获取模型或检测连接时，未输入新密钥就继续使用已保存的密钥。
- 点击“更换”才会打开空的新密钥输入框；“取消”丢弃本次输入。离开设置页或重新加载也会丢弃未保存的更换内容，不影响原密钥。
- “删除密钥”清除已有密钥并恢复初次填写状态。真实密钥不会被填回页面，不写入浏览器存储或源码。

## 下载与升级

下载 **`auto-bgm-setup-1.0.4.exe`**，适用于 Windows x64。内含 FFmpeg、
faster-whisper small、YAMNet 和本机运行组件，无需另装 Python 或下载模型。

旧独立版可在“关于”页检查更新。1.0.2 起也会在空闲检查到新版本时显示提醒；
后台检查最多每 24 小时一次，手动检查不受此限制。不会自动下载或强制重启。
覆盖安装保留本机 API 配置、曲库缓存和快捷方式，原视频及音乐不会被修改。

`.blockmap` 和 `latest.yml` 是更新器配套文件，普通用户只需下载安装包。
安装包尚未签名，Windows 可能显示未知发布者，请核对下载来源和文件校验值。

安装包大小：`689215393` 字节。SHA-256：

```text
55207b4510cf85bb184e65991ec1e8014fca7654b59e8cbee622cc7c6c7b02a3
```

## 保留功能与隐私

同名音乐去重、剧情辅助、自定义兼容 API、多层曲库、自定义每集配乐上限、
批量生成、人声筛选与时间轴审阅继续保留。默认处理在本机完成；
开启剧情辅助才向配置的服务发送剧本、带时间对白及类别摘要，服务可能收费，
不上传音乐、视频或曲库路径。不附带私人密钥、个人设置或素材。

这是自动配背景音乐的软件，不是人物台词配音或声线克隆工具。
