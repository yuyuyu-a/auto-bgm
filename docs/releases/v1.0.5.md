# 自动配乐 v1.0.5

## 本次更新

- 缺少目标曲风时，先使用剧情相近的合格音乐，不再因为目录缺少对应分类而生成意外的“中性留白”。
- 曲库没有浪漫、温情时，可使用抒情类纯音乐替代，优先于励志或中性音乐。仍优先使用原曲风，不拿相反情绪的音乐凑数。
- 支持 `抒情`、`03_抒情` 和藏在合集里的多层抒情目录。依据目录分类与已有强度设置选曲，不是新增听音识别情绪。
- 替代选曲会记录原始需求、实际分类、替代原因，并标记待试听。
- 规则模式下，同一首音乐跨情绪段继续使用时保持连续播放，避免从头重播或与自身交叉淡化。
- 纯音乐筛选、禁用、同名去重和必须换曲的场景规则继续生效。完全没有合适曲目时明确提示补充曲库，不会静默输出空配乐。
- 剧本明确安排的“剧情留白”和片尾定格仍保留。已生成的旧成片不自动覆盖，需重新生成才能使用新规则。

## 下载与升级

下载 **`auto-bgm-setup-1.0.5.exe`**，适用于 Windows x64。
内含 FFmpeg、faster-whisper small、YAMNet 和本机运行组件，无需另装 Python 或下载模型。

旧版可在“关于”页检查更新，或等待空闲时的新版本提醒。后台检查最多每 24 小时一次，
手动检查不受此限制。不会自动下载或强制重启；安装更新会保留本机配置、曲库缓存和快捷方式。

`.blockmap` 和 `latest.yml` 是更新器配套文件，普通用户只需下载安装包。
安装包尚未签名，Windows 可能显示未知发布者，请核对下载来源和文件校验值。

安装包大小：`689217288` 字节。SHA-256：

```text
725d63166abd9f136102879dfd752276980d110ce0c63d7edd8f3e5cf990f3e7
```

## 保留功能与隐私

密钥加密保存与固定掩码、剧情辅助、可配置 API、多层曲库、
自定义每集配乐数量、批量生成和时间轴审阅继续保留。
默认处理在本机完成；开启剧情辅助才向配置的服务发送剧本、带时间对白和分类摘要，
服务可能收费，不上传音乐、视频或曲库路径。不附带私人密钥、个人设置或素材。

这是自动配背景音乐的软件，不是人物台词配音或声线克隆工具。
