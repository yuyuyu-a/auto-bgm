# 自动配乐 v1.0.3

## 本次更新

- 全曲库及多层子目录中的同名音乐只分析、使用一份，忽略完整文件名的大小写。在解码和整曲人声分析前跳过副本，减少重复处理。
- 按路径自然顺序固定选择一份，保留所有情绪目录分类。界面显示跳过的同名副本和实际使用的文件，不删除、移动或修改你的音乐。
- 同名音乐不再重复计入曲库总数或每集不同曲目下限。已禁用、损坏或未通过筛选的曲目不会通过同名副本绕过筛选。
- 这是按名字去重，不是音频指纹识曲：`theme.mp3` 与 `THEME.MP3` 合并；`theme.wav`、`theme (1).mp3` 与它分别保留。

## 下载与升级

下载 **`auto-bgm-setup-1.0.3.exe`**，适用于 Windows x64。内含 FFmpeg、
faster-whisper small、YAMNet 和本机运行组件，无需另装 Python 或下载模型。

旧独立版可在“关于”页检查更新。1.0.2 起也会在空闲检查到新版本时显示提醒；
后台检查最多每 24 小时一次，手动检查不受此限制。不会自动下载或强制重启。
覆盖安装保留本机 API 配置、曲库缓存和快捷方式，原视频及音乐不会被修改。
旧成片不会自动变化，需要重新生成才能使用新的去重规则。

`.blockmap` 和 `latest.yml` 是更新器配套文件，普通用户只需下载安装包。
安装包尚未签名，Windows 可能显示未知发布者，请核对下载来源和文件校验值。

安装包大小：`689215035` 字节。SHA-256：

```text
bb7a4adbd451047c94ab8d019d455dee855e57d6f45f4c9f45e47d70a257b078
```

## 保留功能与隐私

剧情辅助、自定义兼容 API、多层曲库、自定义每集配乐上限、批量生成、
人声筛选与时间轴审阅继续保留。默认处理在本机完成；开启剧情辅助才向配置的
服务发送剧本、带时间对白及类别摘要，服务可能收费，不上传音乐、视频或曲库路径。
不附带私人密钥、个人设置或素材。
