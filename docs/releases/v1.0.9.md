# 自动配乐 v1.0.9

## 字幕与画面本地配乐

- 新增无需 API 密钥的本地视觉配乐模式，结合视频抽样画面和有时间戳的 `.srt` 字幕，选择已筛选的本地音乐。
- 单集可选择一个 SRT 文件；批量处理时，字幕目录须包含与视频同名的 `.srt` 文件。
- 首次使用时下载并校验约 2.8 GB 的 Qwen2.5-VL 模型和 llama.cpp Windows 运行时。下载文件保存在用户数据目录，不包含在安装包内。
- 下载中断后保留已下载部分；服务器支持 HTTP Range 时可继续下载，完成后仍校验完整文件哈希。
- 支持 Vulkan 时优先使用 GPU；GPU 启动或推理失败时退回 CPU。画面分析、字幕和选曲均在本机运行；下载完成后分析不需要网络或 API。
- 展示抽帧和本地分析进度；分析可取消。字幕时间、画面证据或音乐类别无效时会停止该集并说明原因，不会自行补静音。
- 低置信度结果会标记为待复核。请检查时间轴、对白和试听成片。

下载 `auto-bgm-setup-1.0.9.exe` 覆盖安装，原有配置和素材会保留。软件内更新使用的 `.blockmap` 与 `latest.yml` 与安装包一并发布。
