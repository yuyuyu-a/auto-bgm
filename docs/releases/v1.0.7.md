# 自动配乐 v1.0.7

## 单曲连续播放上限

- 设置 → 换曲与衔接新增“单曲最长连续播放”，默认 40 秒，可自行修改，填 0 表示不限制。设置保存在本机，重启后无需重填。
- 同一文件跨相邻剧情或情绪片段连续使用时累计计时，重新播放或拆分标签不会绕过上限。实际发声时长包含淡入淡出；到点更换另一首合格音乐。
- 换曲优先同类音乐，再使用已有相近曲风或兼容中性曲目。浪漫、温情不足时仍可使用抒情替代，不会用相反情绪补数。
- 时长换曲优先于每集片段上限；规则模式和剧情辅助均生效，无需额外调用剧情 API。
- 没有另一首合适的已筛选音乐时，明确显示时间点与补充曲目的提示，不会重播原曲伪装换曲，也不会输出意外的“中性留白”。
- 保留剧本明确要求的剧情留白、片尾定格、场景转场与剧情证据。CSV 增加配置上限与实际播放范围。

## 更新注意

- 继续保留 v1.0.6 的旧版意外留白自动重配修复，以及密钥加密保存、多层曲库、同名去重和抒情替代。
- 新上限用于新生成或主动重新生成的结果。已有正常成片不会因修改设置而后台改写；需要应用时，使用单集重新生成或关闭“跳过已完成”后运行。
- 在实际使用的电脑安装 `auto-bgm-setup-1.0.7.exe`；覆盖更新保留本机配置和素材。软件不会替用户远程安装到另一台电脑。
- 本版本不附带私人密钥、视频或曲库。
