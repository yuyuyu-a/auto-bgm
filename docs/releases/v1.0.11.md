# 自动配乐 v1.0.11

## 本地画面分析自动分批

- 本地“字幕 + 画面”配乐将最多 24 张抽样画面分成较小批次，并为每批提供对应字幕锚点。
- 相邻批次共享一帧作为上下文，同时只允许每批对其负责的画面时刻生成配乐锚点。
- 如果视觉模型仍返回截断结果，该批会继续拆分并重试；各批次按字幕锚点合并为完整时间线。
- 进度中显示批次拆分状态。最小画面/字幕批次仍被截断时，会返回明确错误，而不是错误地要求缩短整段视频。
- 不改变 SRT 文件，不上传视频、字幕、曲库或抽帧；无需额外 API，也无需重新下载模型。
- 曲库并行扫描结果按稳定顺序处理，避免内容相同的曲目在重复检查时交换代表项。
