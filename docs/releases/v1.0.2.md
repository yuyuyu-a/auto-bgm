## 下载与升级

下载 **`auto-bgm-setup-1.0.2.exe`**，安装后运行“自动配乐”。
适用于 Windows x64，包含 FFmpeg、faster-whisper small、YAMNet 和本机运行组件，
无需额外安装 Python 或下载模型。

现有 1.0.0 / 1.0.1 用户可在“关于”页点击“检查更新”升级；新的提醒弹窗从 1.0.2 起生效。
安装版启动后会检查更新，后台检查最多每 24 小时一次；手动检查不受此限制。
不会自动下载、强制重启或中断正在运行的配乐任务。
覆盖安装保留同一独立版的本机设置和快捷方式身份。

`Source code` 是源码；`.blockmap` 和 `latest.yml` 是供软件更新器使用的配套文件，
普通用户无需手动打开。仅上传源码不会触发软件升级。

安装包目前没有代码签名证书，Windows 可能显示未知发布者，请核对下载来源与文件校验值。

安装包大小：`689215200` 字节。SHA-256：

## 保留功能与隐私

剧情辅助、自己的兼容 API、多层曲库扫描、自定义配乐上限、批量处理和时间轴审阅继续保留。
默认配乐与语音转录在本机处理；开启剧情辅助时只向你配置的服务发送剧本、
带时间对白与类别摘要，服务可能收费，不上传视频、音乐文件或曲库路径。
不附带私人 API 密钥、视频、曲库或个人设置。

这是自动配背景音乐的软件，不是人物台词自动配音或声线克隆工具。
