# v1.0.6 Silent Resume Repair And Release

**Goal:** Repair the reproduced legacy accidental-silence resume bug and publish
the tested Windows installer through the existing public update feed.

**Scope:** The user's request approves fixing and publishing the diagnosed
behavior. Keep this checkout and existing release tooling; no new dependencies.

## Design

- Identify old rule-mode segments labelled `中性留白` with no track and no
  explicit story-silence marker. Never reinterpret intentional story silence.
- When a selected output contains this known defect, bypass completed-output
  skipping and replan with the current screened music pool. Empty pools fail
  actionably and leave previous media intact.
- Retain pending repair metadata for deselected artifacts, so a timeline-only
  regeneration cannot certify an unchanged silent WAV or final video.
- Display the regeneration warning in the queue/inspector, explain automatic
  repairs in logs, and retain normal resume for valid current outputs and
  non-silent legacy outputs.
- Keep application identity, credentials, source media, manual-file protection,
  update repository, and intentional story silence unchanged.
